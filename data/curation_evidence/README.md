# EGFR paired-data curation evidence

These records contain only EGFR (UniProt P00533). The curation sequence contains
1,271 strict WT–variant pairs, 1,230 aggregated pair tasks, seven conflict
exclusions and 1,223 accepted training pairs. The JSON audits report counts
for this EGFR subset. Dataset composition is defined by the accepted pairs and
the frozen model-ready splits.
